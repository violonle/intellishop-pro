# Shared Components Directory

This directory contains reusable React components that are used across multiple pages of the application.

## Structure

- `common/`: General purpose components (Buttons, Inputs, Modals, etc.)
- `layout/`: Layout components (Header, Sidebar, Footer)
- `business/`: Business-specific shared components (e.g., ProductCard, CustomerRow)

## Usage

Import components from here to ensure consistency and reduce code duplication.
