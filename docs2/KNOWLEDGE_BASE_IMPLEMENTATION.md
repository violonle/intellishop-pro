# 知识库和文件上传系统实现文档\n\n## 📋 项目概述\n\n本文档记录ShopPro知识库管理和文件上传系统的后端实现，包括数据库表设计、Java实体类、Repository层、Service层和Controller层的完整实现。\n\n---\n\n## 🗄️ 数据库设计\n\n### 已实现的表\n\n#### 1. knowledge_base（知识库内容表）\n- 核心表，存储知识库文章内容\n- 支持富文本HTML内容\n- 支持文件附件URL列表（JSON格式）\n- 支持全文搜索索引\n- 字段：id, title, content, summary, category_id, tags, file_urls, cover_image, view_count, like_count, is_public, is_featured, created_by, updated_by, created_at, updated_at\n\n#### 2. knowledge_categories（知识库分类表）\n- 分类管理表，支持树形结构\n- 字段：id, parent_id, name, description, icon, sort_order, status, created_at, updated_at\n\n#### 3. file_uploads（文件上传记录表）- **新增**\n- 记录所有上传的文件及其元数据\n- 支持审计追踪和重复检测（MD5哈希）\n- 字段：id, original_file_name, saved_file_name, file_url, file_size, mime_type, file_extension, related_entity_type, related_entity_id, uploaded_by, uploaded_by_name, status, md5_hash, download_count, remarks, created_at, updated_at\n\n#### 4. knowledge_access_logs（访问日志表）- **新增**\n- 记录知识库访问情况，用于分析热门内容\n- 字段：id, knowledge_id, user_id, access_ip, user_agent, referer, access_time\n\n#### 5. knowledge_comments（评论表）- **新增**\n- 支持用户评论和反馈，支持评论回复\n- 字段：id, knowledge_id, user_id, user_name, content, rating, helpful_count, parent_comment_id, status, created_at, updated_at\n\n#### 6. knowledge_tags（标签表）- **新增**\n- 标签管理表，用于改进搜索和分类\n- 字段：id, tag_name, tag_count, created_at\n\n#### 7. knowledge_relations（关联表）- **新增**\n- 记录相关知识之间的关系\n- 字段：id, knowledge_id, related_knowledge_id, relation_type, created_at\n\n---\n\n## 🏗️ 后端架构\n\n### Entity层（实体类）\n\n已实现的实体类：\n\n1. **Knowledge.java**\n   - 映射knowledge_base表\n   - 包含所有业务字段\n   - 支持逻辑删除\n   - 自动填充创建/更新时间\n\n2. **KnowledgeCategory.java**\n   - 映射knowledge_categories表\n   - 支持树形结构（parent_id）\n\n3. **FileUpload.java**\n   - 映射file_uploads表\n   - 支持文件审计追踪\n   - 包含MD5哈希值用于重复检测\n\n### Repository层（数据访问层）\n\n基于MyBatis-Plus的Repository接口：\n\n1. **KnowledgeRepository**\n   - 继承BaseMapper<Knowledge>\n   - 方法：searchByKeyword、findByCategory、findFeaturedKnowledge、findHotKnowledge\n\n2. **KnowledgeCategoryRepository**\n   - 继承BaseMapper<KnowledgeCategory>\n   - 方法：findRootCategories、findSubCategories、findCategoryTree\n\n3. **FileUploadRepository**\n   - 继承BaseMapper<FileUpload>\n   - 方法：findByRelatedEntity、findByMd5Hash、findByUploader、countByRelatedEntity\n\n### Service层（业务逻辑层）\n\n1. **KnowledgeService接口 + KnowledgeServiceImpl实现**\n   - listKnowledge：分页查询\n   - searchKnowledge：全文搜索\n   - getKnowledgeDetail：获取详情（自动增加浏览次数）\n   - createKnowledge：创建知识库\n   - updateKnowledge：更新知识库\n   - deleteKnowledge：删除知识库（逻辑删除）\n   - deleteBatch：批量删除\n   - getFeaturedKnowledge：获取推荐知识\n   - getHotKnowledge：获取热门知识\n   - incrementViewCount：增加浏览次数\n   - likeKnowledge：点赞功能\n   - getByCategory：按分类查询\n\n2. **FileStorageService接口**\n   - uploadFile：单个文件上传\n   - uploadFiles：批量文件上传\n   - deleteFile：删除文件\n   - deleteFiles：批量删除文件\n   - getFileInfo：获取文件信息\n   - getFilesByEntity：获取实体相关的所有文件\n   - downloadFile：下载文件\n   - isFileAllowed：验证文件类型和大小\n   - getFileUrl：获取文件访问URL\n   - incrementDownloadCount：增加下载次数\n\n### Controller层（API端点）\n\n**KnowledgeController**\n\n| 方法 | 端点 | 说明 |\n|------|------|------|\n| GET | `/knowledge/list` | 分页查询知识库列表 |\n| GET | `/knowledge/search` | 全文搜索知识库 |\n| GET | `/knowledge/{id}` | 获取知识库详情 |\n| POST | `/knowledge` | 创建知识库（需要ADMIN/MANAGER角色） |\n| PUT | `/knowledge/{id}` | 更新知识库（需要ADMIN/MANAGER角色） |\n| DELETE | `/knowledge/{id}` | 删除知识库（需要ADMIN/MANAGER角色） |\n| GET | `/knowledge/featured` | 获取推荐知识 |\n| GET | `/knowledge/hot` | 获取热门知识 |\n| POST | `/knowledge/{id}/like` | 点赞知识库 |\n| GET | `/knowledge/category/{categoryId}` | 按分类查询知识库 |\n\n---\n\n## 📁  文件上传配置\n\n### FileUploadConfig\n\n从application.yml读取配置：\n\n```yaml\nfile:\n  upload:\n    path: /data/shoppro/uploads/              # 文件保存路径\n    url-prefix: http://localhost:8080/api/files/  # 文件访问URL前缀\n    allowed-types: jpg,jpeg,png,gif,pdf,doc,docx,xls,xlsx,ppt,pptx,txt  # 允许的文件类型\n    max-size: 10485760  # 最大文件大小（字节），10MB\n```\n\n---\n\n## 🔄 工作流程\n\n### 知识库创建流程\n\n```\n1. 前端编辑富文本内容\n2. 上传相关附件文件\n3. POST /knowledge 创建知识库\n   - FileStorageService处理文件上传\n   - KnowledgeService保存知识库记录\n   - 返回知识库ID和访问URL\n```\n\n### 文件上传流程\n\n```\n1. 前端选择文件\n2. POST /upload 上传文件\n   - FileUploadConfig验证文件类型和大小\n   - 生成唯一文件名\n   - 计算MD5哈希值检测重复\n   - 保存文件到/data/shoppro/uploads/\n   - FileUploadRepository记录文件元数据\n3. 返回文件URL和记录ID\n```\n\n### 知识库搜索流程\n\n```\n1. 前端输入搜索关键词\n2. GET /knowledge/search?keyword=xxx&pageNo=1&pageSize=10\n3. KnowledgeService执行全文搜索\n   - 查询title、content、summary字段\n   - 使用FULLTEXT索引加速查询\n   - 过滤已删除记录和私有记录\n4. 返回分页搜索结果\n```\n\n---\n\n## 🛠️ 待实现任务\n\n### 高优先级\n\n- [ ] **FileStorageServiceImpl** - 文件存储服务具体实现\n  -
