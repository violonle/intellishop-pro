## 📋 详细测试流程

### 第1部分: 功能测试 (30分钟)

#### A. Leads页面测试

**基础测试** (5分钟)
```
1. 观察页面加载
   ✓ 页面正常显示
   ✓ 线索列表加载
   ✓ UI组件就位

2. 检查样式
   ✓ 优先级颜色正确
   ✓ 布局美观
   ✓ 响应式工作
```

**搜索功能** (5分钟)
```
1. 输入: "李先生"
   等待 500ms
   观察列表更新

2. 输入: "王女士"
   等待 500ms
   观察列表更新

3. 清空输入
   验证列表恢复
```

**筛选功能** (5分钟)
```
按次序点击每个筛选按钮:
- [ ] 全部
- [ ] 高优先级
- [ ] 今日跟进
- [ ] 待分配
- [ ] 已成交

记录: 每次点击后列表是否正确更新
```

**分配功能** (5分钟)
```
找到"陈小姐"(待分配状态):
1. 点击"智能分配"按钮
   观察: 弹窗是否出现
   
2. 等待推荐结果
   观察: 是否显示推荐销售
   
3. 点击确认
   观察: UI是否更新

记录任何错误或异常
```

**AI功能** (5分钟)
```
选择一个线索(如李先生):
1. 点击"AI预测"
   观察: 是否显示成交概率
   
2. 点击"智能话术"
   观察: 是否显示推荐话术

记录响应时间和内容质量
```

#### B. Product页面测试

**快速检查** (10分钟)
```
1. 打开 pages/product-management.html

2. 检查列表加载
   ✓ 产品显示
   ✓ 库存显示
   ✓ 价格显示

3. 尝试CRUD操作
   ✓ 创建新产品
   ✓ 编辑产品
   ✓ 删除产品

4. 库存管理
   ✓ 入库操作
   ✓ 出库操作
   ✓ 预警提示
```

### 第2部分: 性能测试 (15分钟)

**方式1: 使用诊断脚本** (推荐)

```javascript
// 打开浏览器 DevTools Console
// 复制粘贴以下命令

window.runPhase3Diagnostics()

// 等待完成，查看输出结果
// 记录关键指标:
// - 页面加载时间
// - 内存占用
// - 网络请求数
// - 脚本执行时间
```

**方式2: 手工检查**

```
1. DevTools → Performance 标签
   - 刷新页面
   - 记录加载时间 (目标 < 2s)
   
2. DevTools → Memory 标签
   - 记录初始内存
   - 加载数据后记录
   - 检查是否有泄漏
   
3. DevTools → Network 标签
   - 刷新页面
   - 查看请求总数 (目标 < 50)
   - 查看总大小 (目标 < 2MB)
```
