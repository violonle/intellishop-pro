# 弹出面板标准规范

## 统一div弹出面板标准

为确保所有弹出面板的一致性和用户体验，制定以下标准规范：

### 1. 基础结构标准

```html
<!-- 弹出面板容器 -->
<div id="modalId" class="fixed inset-0 z-50 hidden">
    <!-- 背景遮罩层 -->
    <div class="modal-overlay absolute inset-0 bg-black bg-opacity-50" onclick="hideModal()"></div>
    
    <!-- 面板内容区域 -->
    <div class="modal-content">
        <!-- 具体内容 -->
    </div>
</div>
```

### 2. 样式类标准

#### 2.1 容器样式
- **必须使用**: `fixed inset-0 z-50 hidden`
- **z-index**: 统一使用 `z-50`
- **初始状态**: 必须包含 `hidden` 类

#### 2.2 背景遮罩层样式
- **必须使用**: `modal-overlay absolute inset-0`
- **背景色**: `bg-black bg-opacity-50` 或 `bg-black/50`
- **点击事件**: 必须绑定关闭弹窗的onclick事件

#### 2.3 内容区域样式
根据弹窗类型选择：

**底部滑出式（推荐用于移动端）：**
```html
<div class="absolute bottom-0 left-0 right-0 bg-white rounded-t-2xl slide-up">
```

**居中弹窗式（推荐用于桌面端）：**
```html
<div class="flex items-center justify-center min-h-screen p-4">
    <div class="bg-white rounded-xl shadow-xl max-w-md w-full transform transition-all">
```

### 3. JavaScript函数标准

#### 3.1 显示弹窗函数
```javascript
function showModal(modalId) {
    document.getElementById(modalId).classList.remove('hidden');
}
```

#### 3.2 隐藏弹窗函数
```javascript
function hideModal(modalId) {
    document.getElementById(modalId).classList.add('hidden');
}
```

### 4. 动画效果标准

#### 4.1 CSS动画类
```css
.slide-up {
    animation: slideUp 0.3s ease-out;
}

@keyframes slideUp {
    from {
        transform: translateY(100%);
    }
    to {
        transform: translateY(0);
    }
}
```

### 5. 关闭按钮标准

```html
<button onclick="hideModal('modalId')" class="p-2 hover:bg-gray-100 rounded-lg transition-colors">
    <svg class="w-5 h-5 text-gray-500" fill="none" stroke="currentColor" viewBox="0 0 24 24">
        <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M6 18L18 6M6 6l12 12"></path>
    </svg>
</button>
```

### 6. 需要统一修改的文件列表

1. **leads.html** - 自动分配弹窗、手动分配弹窗
2. **notifications.html** - 通知设置弹窗
3. **settings.html** - 确认弹窗
4. **ai-scripts.html** - 新建脚本弹窗
5. **leads-fixed.html** - 各种分配弹窗

### 7. 修改原则

1. **保持功能不变** - 只修改样式和结构，不改变业务逻辑
2. **统一用户体验** - 所有弹窗使用相同的视觉风格和交互方式
3. **响应式设计** - 确保在不同设备上都有良好的显示效果
4. **无障碍访问** - 保持键盘导航和屏幕阅读器兼容性

### 8. 验证标准

修改完成后需要验证：
- [ ] 弹窗能正常显示和隐藏
- [ ] 背景遮罩层点击能关闭弹窗
- [ ] 关闭按钮功能正常
- [ ] 动画效果流畅
- [ ] 在不同屏幕尺寸下显示正常
