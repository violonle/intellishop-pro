# API 集成文档\n\n## 概述\n本项目已集成 API 客户端，前端页面现在调用真实的 API 接口。\n\n## 已更新的页面\n\n### 1. customer-management.html（客户管理）\n**新增 API 调用：**\n- `api.customers.list()` - 加载客户列表\n- `api.customers.create()` - 添加新客户\n\n**集成位置：**\n- `loadCustomersFromAPI()` - 页面加载时从 API 获取客户列表\n- 添加客户表单提交事件 - 调用 API 创建新客户\n\n**Fallback 机制：**\n- 如果 API 失败，自动使用本地模拟数据\n- 错误会通过 UI 消息提示给用户\n\n### 2. customer-detail.html（客户详情）\n**新增 API 调用：**\n- `api.customers.get(id)` - 获取单个客户详情\n- `api.customers.update(id, data)` - 更新客户信息\n\n**集成位置：**\n- `loadCustomerData()` - 页面加载时从 API 获取客户详情（通过 URL 参数 ?id=X）\n- 编辑保存按钮 - 调用 API 更新客户信息\n\n**参数传递：**\n- 通过 URL 查询参数 `?id=1` 传递客户 ID\n- 从 URL 参数中获取客户 ID 后调用 API\n\n## API 客户端配置\n\n### 文件位置\n`/assets/js/api-client.js`\n\n### 配置说明\n```javascript\n// 默认 API 地址\nthis.apiURL = `${this.baseURL}/api`\n\n// 默认超时和重试配置\nthis.config = {\n    timeout: 30000,      // 30秒超时\n    retries: 3,          // 失败重试3次\n    retryDelay: 1000     // 重试延迟1秒\n}\n```\n\n### 环境变量支持\n可通过以下方式覆盖 API 地址：\n\n```javascript\n// 全局变量\nwindow.API_BASE_URL = 'http://your-api-domain.com'\nwindow.API_URL = 'http://your-api-domain.com/api'\n\n// 或 localStorage\nlocalStorage.setItem('API_BASE_URL', 'http://your-api-domain.com')\nlocalStorage.setItem('API_URL', 'http://your-api-domain.com/api')\n```\n\n## 可用的 API 方法\n\n### 客户管理
