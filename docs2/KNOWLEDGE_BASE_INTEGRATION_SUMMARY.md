## 📝 快速开始

### 访问知识库管理页面

```bash
# 1. 启动后端服务
cd backend && mvn spring-boot:run

# 2. 启动前端HTTP服务
python3 -m http.server 8000

# 3. 访问知识库管理页面
http://localhost:8000/pages/knowledge-management.html
```

### 使用流程

1. **登录** → 进入系统（确保JWT Token有效）
2. **打开知识库管理** → 页面自动加载知识库列表
3. **新建知识库**：
   - 点击"新建知识库"按钮
   - 填写标题、选择分类、编写内容
   - 可选：添加摘要、标签、上传附件
   - 点击保存
4. **编辑知识库**：
   - 点击列表中的编辑按钮
   - 修改内容
   - 点击保存
5. **删除知识库**：
   - 点击列表中的删除按钮
   - 确认删除
6. **搜索知识库**：
   - 输入关键词或选择分类
   - 点击搜索按钮
   - 查看搜索结果

## 📞 技术支持

### 常见问题

**Q: 知识库列表加载失败**  
A: 检查后端服务是否运行，API地址是否正确配置

**Q: 文件上传失败**  
A: 检查文件大小是否超过10MB，文件类型是否在白名单中

**Q: 富文本编辑器加载失败**  
A: 确保网络连接正常（需要加载TinyMCE CDN）

**Q: 搜索没有结果**  
A: 检查搜索关键词是否正确，数据库中是否有相关数据
